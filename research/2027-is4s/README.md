## 2027 program research and learning design

**Working draft · 22 October 2026 · All cohort dates remain tentative**

Build from a real task. Show the steps. Practise together. Check the result. Explain where the skills were used.

### What is established so far

- **Reviewed directly:** the supplied program reference, the three visible lesson pages, and the Numeracy Hub repository, including its brand guidance and instructional structure.
- **Proposed here:** learning challenges, skill evidence, scaffolds, numeracy examples and the pilot lesson. These are curriculum-development drafts rather than provider-approved assessments.
- **Awaiting external verification:** current program prerequisites, credits, code/manual editions, certification dates, purchasing lists and clinical/licensing rules. Requests to the official research sites received a network-proxy `403 Forbidden`; the environment network changes were saved as a draft but have not been confirmed active.
- **Awaiting partner confirmation:** actual ACCESS course codes, delivery hours, dates, provider-specific requirements and funded supports. Public reference programs do not establish the content of a dedicated ACCESS cohort.

### Build the next teaching materials in this order

1. **Confirm scope and sources.** Establish the actual course/level and approved assessment outcomes for each cohort. Resolve the Tower Crane date and pathway questions first because the supplied reference flags a possible regulatory change.
2. **Pilot common foundations.** Use the paper-glider lab to observe learners' strategies, then select numeracy support from the existing Hub. Treat prior experience as a strength; offer private, practical feedback.
3. **Develop Welding and Asphalt first.** These are the earliest tentative starts. Obtain one approved work document per program and expand each starter into a complete learner sheet, worked example, instructor notes and short assessment.
4. **Extend the same pattern to the remaining cohorts.** Map each finished activity to a specific current competency after the provider confirms the course scope. Use skills tags consistently, without treating a tag as evidence of proficiency.
5. **Review with ACCESS and instructors.** Check relevance, accessibility, community preferences, technical accuracy, permissions for materials and assessment expectations before learner delivery.
