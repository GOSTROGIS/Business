## Verification queue

[Open the CSV register](verification-register.csv). Each row identifies a material claim or decision, its provenance, the exact question to resolve and its status. Append the retrieved document URL, effective date and page/section when checked. A provider decision cannot be resolved solely by a public website.

Use these statuses consistently:

- **Supplied only:** recorded in S01 but not independently checked.
- **Repository checked:** directly observed in the specified H01 commit.
- **Conflicting supplied information:** two parts of S01 disagree.
- **Partner confirmation pending:** an ACCESS-specific arrangement that the selected provider must confirm.
- **Proposed learning activity:** original teaching design awaiting review/pilot.
- **Primary source checked:** use only after retrieving the exact current source and recording what it supports. None of the external program requirements in this first pack have this status.
