# Metal Fabrication — develop and check a pattern and parts plan

[All programs](README.md) · [Teaching framework](../framework.md) · [Worked numeracy starters](../numeracy-starters.md)

**Research stage:** Initial learning-design draft. Activities are proposed for ACCESS/instructor review. Cohort and public-program details come from [the supplied reference](../sources/supplied-program-reference-2026-10-22.txt), section “Metal Fabrication”, and have not been independently confirmed.

**Supplied context:** September 14–November 6, 2027; Trades; BCIT. Confirm the actual fabrication scope, practical assessment and progression outcomes.
**Integrated challenge:** Turn an instructor-approved simple drawing into a paper/card pattern, prepare a parts and materials list, and revise the layout after a specification change.
**Inputs to request:** Approved drawing, material dimensions, pattern template, measurement tools and instructor-defined allowances; machine settings and physical fabrication remain partner-led.

| Skill | Proposed activity → observable evidence |
|---|---|
| Reading | Interpret the drawing's dimensions, notes and part identifiers → annotated drawing linked to each pattern feature. |
| Writing | Record a clear sequence and inspection observations → work sheet that identifies what was checked and any unresolved discrepancy. |
| Numeracy | Calculate pattern dimensions and area using instructor-taught methods → labelled workings and measured pattern check. |
| Digital | Prepare or annotate a simple digital parts layout using available software → saved file with dimensions, units and revision label. |
| Problem solving | Find why the first pattern does not fit the model requirements → evidence-based correction using the drawing and approved allowances. |
| Communication | Explain a drawing ambiguity and request a precise clarification → question includes the part, dimension and conflicting information. |
| Collaboration | Exchange pattern and parts list for independent checking → recorded peer feedback and an agreed correction. |
| Adaptability | Revise the pattern when one specification changes → updated layout with affected dimensions identified. |
| Creativity and innovation | Compare two permitted nesting arrangements on a paper sheet → reasoned choice based on material use and clarity. |

**Accessible entry / stretch:** Start with a simple flat shape, large dimensions and a partly labelled template; extend to a folded model or a more complex layout after instruction.
**Evidence bundle:** Annotated drawing, pattern, parts list, calculation sheet and revision comparison.
**Research/provider questions:** Which materials, machines and fabrication processes are included? Which drawing conventions and tolerances will be taught? Which references, consumables and assessment projects are supplied?
