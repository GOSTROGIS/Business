# Security — observe, record and hand over a fictional incident

[All programs](README.md) · [Teaching framework](../framework.md) · [Worked numeracy starters](../numeracy-starters.md)

**Research stage:** Initial learning-design draft. Activities are proposed for ACCESS/instructor review. Cohort and public-program details come from [the supplied reference](../sources/supplied-program-reference-2026-10-22.txt), section “Security”, and have not been independently confirmed.

**Supplied context:** September 14–November 6, 2027; Programs; provider TBD. Confirm the approved training provider and additional cohort content separately from licensing requirements.
**Integrated challenge:** Observe a low-intensity scripted event, create a factual incident record and provide a respectful shift handover using a provider-approved response protocol.
**Inputs to request:** Fictional site map, observation script, report template, communication protocol and authorized curriculum excerpts; use invented names and no real surveillance footage.

| Skill | Proposed activity → observable evidence |
|---|---|
| Reading | Locate relevant instructions in fictional post orders and a site map → cited instruction and accurately identified location. |
| Writing | Produce an objective incident report → chronological account that separates direct observation, quoted statements and uncertainty. |
| Numeracy | Calculate elapsed time and reconcile event timestamps → timeline with checked intervals and consistent time notation. |
| Digital | Enter the report in a practice form and handle a fictional attachment → complete record with correct file naming and instructor-taught privacy handling. |
| Problem solving | Select the next step from provider-approved scenario options → reasoning tied to known facts, role limits and escalation instructions. |
| Communication | Practise respectful clarification and a concise radio-style handover → clear message without speculation or stigmatizing language. |
| Collaboration | Compare witness notes and reconcile differences without changing original observations → joint timeline retaining the source of each account. |
| Adaptability | Update the report when a new verified detail is supplied → dated addition that preserves the original account. |
| Creativity and innovation | Redesign a practice handover aid for readability → tested prompt sheet that improves completeness without changing approved procedures. |

**Accessible entry / stretch:** Begin with still images, a short script and report headings; extend to several accounts, ambiguous details and a longer timeline. Allow opt-out from distressing role-play content.
**Evidence bundle:** Incident report, timeline, digital practice record and handover observation.
