# Ironworker — reconcile a drawing and component inventory

[All programs](README.md) · [Teaching framework](../framework.md) · [Worked numeracy starters](../numeracy-starters.md)

**Research stage:** Initial learning-design draft. Activities are proposed for ACCESS/instructor review. Cohort and public-program details come from [the supplied reference](../sources/supplied-program-reference-2026-10-22.txt), section “Ironworker”, and have not been independently confirmed.

**Supplied context:** March 15–May 7, 2027; Trades; BCIT. Confirm whether this cohort concerns Generalist, Reinforcing, introductory exposure or another defined scope.
**Integrated challenge:** Assemble a tabletop model from an instructor-selected drawing, reconcile labelled model components and produce a handover listing unresolved discrepancies.
**Inputs to request:** Approved simplified drawing, revision history, model components, fictional inventory and provider-selected terminology. Exclude live lifting or structural decisions from this classroom task.

| Skill | Proposed activity → observable evidence |
|---|---|
| Reading | Match component marks and drawing notes to the inventory → marked drawing and correctly identified model parts. |
| Writing | Document missing or inconsistent components → discrepancy report with location, identifier and required clarification. |
| Numeracy | Count pieces and compare model dimensions with the drawing → checked quantity-and-measurement table with units. |
| Digital | Locate the assigned drawing revision and update a component register → correctly named file and revision recorded in the register. |
| Problem solving | Resolve a model-assembly mismatch by checking source documents → evidence trail identifying whether information is missing or inconsistent. |
| Communication | Practise an instructor-approved confirmation exchange for the tabletop task → clear request, repeat-back and confirmation observed. |
| Collaboration | Coordinate model assembly and independent checking → agreed roles and an identified correction from peer review. |
| Adaptability | Incorporate a revised component list without losing the original record → versioned list showing what changed and why. |
| Creativity and innovation | Propose a more readable model-part labelling system → test labels another learner can interpret accurately. |

**Accessible entry / stretch:** Start with large printed identifiers and a small model; extend to a larger inventory or reconciling two drawing revisions.
**Evidence bundle:** Component register, tabletop model, discrepancy report, revision record and communication observation.
**Research/provider questions:** Which trade pathway and competency outcomes apply? Which drawing conventions and current manuals are used? What rigging, height-work and practical instruction are included under qualified supervision?
