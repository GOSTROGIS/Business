## Historical Essential Skills and current Skills for Success

Use the current nine skill names for new IS4S resources. Retain historical labels when describing the archived lesson. This crosswalk is a design aid, not a one-to-one official equivalence table.

| Historical Essential Skills term | Treatment in new resources |
|---|---|
| Reading / Reading Text | Reading: locating, interpreting and using written information; demonstrate understanding through the task. |
| Document Use | Embed across Reading, Numeracy, Writing and Digital according to the document task: interpreting a chart, extracting a measurement, completing a form or navigating a digital record. Keep document literacy visible. |
| Writing | Writing: producing useful, accurate messages, forms, logs and explanations for a specified audience. |
| Numeracy | Numeracy: selecting and using numbers, measurements, quantities, time and data, then checking whether the result makes sense. |
| Oral Communication | Communication: understanding, exchanging and checking information through appropriate spoken, nonverbal and other modes. |
| Thinking | Problem solving captures much reasoning and decision-making; some tasks also involve Creativity and innovation or Adaptability. Map the actual behaviour. |
| Working with Others | Collaboration: agreeing roles, coordinating work, exchanging feedback and contributing to a shared result. |
| Computer Use | Digital: finding, creating, managing and communicating information with digital tools; broader than basic computer operation. |
| Continuous Learning | A practice running across all nine: reflect, seek feedback, practise and transfer. Adaptability may be demonstrated when a learner changes approach, but it is not simply a renamed Continuous Learning category. |
| No separate historical category | Creativity and innovation is an explicit current skill: generate, test and improve a useful idea within the task's constraints. |

Current nine: Reading; Writing; Numeracy; Digital; Problem solving; Communication; Collaboration; Adaptability; Creativity and innovation.

## What to retain from the photographed lesson

- An inviting, concrete opening; clear purpose; a brief pre-assessment; hands-on practice; learner explanation; a short post-assessment; and a summary.
- Separate instructor and learner activity columns, with resources and estimated time.
- A task that gives learners something visible to make, try, discuss and improve.
- Questions that help learners name skills they already use and transfer them to another situation.
- A practice/debrief cycle rather than a long abstract introduction to skill definitions.

## What to strengthen for a new nine-skills version

- The original visible activity primarily supports following a folding document, problem solving, discussion and turn-taking. It does not visibly generate performance evidence for all nine current skills. Merely naming a skill during the debrief is not evidence of using it.
- Make numeracy observable: estimate flight distance, measure repeated trials with a stated unit, record results in a table, compare results and explain variation. Use measurements appropriate to learners' readiness.
- Add a short written prediction and results note; a simple digital table or graph where access permits; a paired explanation with a comprehension check; shared testing roles; an announced condition change; and a learner-designed revision with a reason.
- Assess a few focus skills per lesson and rotate emphasis across the program. All nine can be visible across a learning sequence without making every short task carry nine equally weighted assessments.
- Use task evidence, a brief learner explanation and instructor observation together. A strong written answer should not mask missing practical understanding; reading or writing support should not be misread as lack of reasoning.
- Offer accessible materials, large-print/visual instructions, demonstration, assistive tools and varied response modes while preserving the skill being assessed. Record the support used where it affects interpretation.
- Use a controlled launch area, suitable materials and alternatives to throwing. Reconsider the original prize/competition format: collaborative accuracy or improvement can support participation without requiring a public ranking.
- Keep the historical aircraft narrative as source content pending fact-checking, or replace it with a short verified context. Do not turn an unverified aerospace claim into a new learning objective.
