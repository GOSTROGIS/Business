FILE FORMATS STUDY — ORIGINAL ACCESS IS4S EXAMPLE
Synthetic voice: Flite slt, generated locally. No real person is represented.

Choose the file for the job
This is a synthetic study voice. Choose the file format for the work you need to do. Keep an editable master and a checked reading copy.
Visual: EDITABLE MASTER  +  CHECKED READING COPY

DOCX keeps wording editable
A D O C X document lets you revise words, headings and tables. Use it for an editable notice. Open the saved file and check its contents.
Visual: DOCX  /  WORDS · HEADINGS · TABLES

XLSX keeps calculations working
An X L S X workbook can keep sheets and formulas. Change an input, inspect the formula and check that the total recalculates.
Visual: XLSX  /  INPUT → FORMULA → CHECKED TOTAL

PDF keeps a reading copy
A P D F is a page based reading copy. Check every page for missing rows or cut off words. Keep the editable source as well.
Visual: PDF  /  OPEN EVERY EXPORTED PAGE

Your turn
A quantity changes. Which file should you update first: the working workbook or its old P D F copy? Pause and explain your choice.
Visual: WHICH FILE SHOULD CHANGE FIRST?
