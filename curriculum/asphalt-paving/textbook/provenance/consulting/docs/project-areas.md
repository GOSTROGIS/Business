# Project areas and stable extent navigation

The map supports up to 24 named areas. Use the map view, or open Project areas and select a country, province/state, region/county and municipality/town or equivalent. Use selected area replaces the current list; Add selected area adds another extent. Each selected area can be removed or revisited independently. Dashed rectangles show the saved extents.

Areas select the union of separate extents. The space between distant areas is not itself selected. Point, line and polygon records intersecting an extent remain whole, with original attributes and geometry. Raster tiles outside the selected areas are suppressed. Live vector queries intersect each saved area with the current viewport and deduplicate returned identities before fetching records; they do not expand into one large intervening rectangle. Clearing an area filter restores the original loaded collection. Data snapshots and live query limits retain their existing provenance and bounds.

Administrative locations use Statistics Canada's 2025 census subdivision hierarchy and the Census Bureau's current TIGERweb vintage. These are published rectangular navigation/filter envelopes. A census subdivision, census-designated place or county subdivision is not necessarily an incorporated municipality. U.S. places can span counties: state places and county subdivisions remain separate choices. Names, identifiers, types, dates and attribution are retained. No municipal boundary shape, clipped municipality statistic or interpolated local value is invented; a national indicator may have a coarser published reporting geography.

Zoom to extent prefers the active project areas, then visible feature bounds, then known source coverage. It no longer downloads or selects a national layer just to move the map. Extent fits stop earlier animation, disable expensive zoom transitions, clamp polar latitudes to the display projection and handle dateline envelopes. Late data downloads cannot invoke a delayed zoom.

Original collections stay intact in memory. Leaflet feature objects are created only for included records and reused as filters change, rather than building a full national layer twice. Geometry bounds are computed iteratively and cached. Opacity, metric selection, layer order, visibility and Clear map retain their existing behavior. Area filters also apply to loaded weather observations and warnings; expired warnings do not reappear when a filter is cleared.

Validation combines geographic unit tests, source and loader tests, isolated browser workflows, actual national cattle data and official municipality lookups. Recurring interface review exercises map interactions using explicit fixtures; live source availability is checked separately. The national coverage backlog remains in implementation-backlog.md.
