Operating Swing Lock

IMPORTANT: To prevent possible machine damage, remove swing lock pin before operating backhoe.

Disengaging the Swing Lock

Remove swing lock pin (A) from swing lock mounting hole (B) and install pin in storage position in operator's station.

Engaging the Swing Lock

Remove swing lock pin (A) from storage position in operator's station and install pin in swing lock mounting hole (B).
