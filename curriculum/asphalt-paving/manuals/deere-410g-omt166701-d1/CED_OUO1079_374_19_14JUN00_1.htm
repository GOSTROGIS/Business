Extendible Dipperstick Locking Pin-If Equipped

CAUTION: To prevent serious injury, always install extendible dipperstick locking pin from ground.

1. Lower backhoe to ground and turn engine off before removing or installing extendible dipperstick locking pin.

2. Install extendible dipperstick locking pin (A) in storage position (B) and retain with quick-lock pin when not transporting the machine.

3. Install locking pin and retain with quick-lock pin in locking position (C) when transporting the machine.


A-Extendible Dipperstick Locking Pin
B-Storage Position
C-Locking Position
