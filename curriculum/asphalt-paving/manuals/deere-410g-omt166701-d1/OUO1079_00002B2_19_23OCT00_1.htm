Checking Neutral Start System

CAUTION: Avoid possible injury or death. DO NOT attempt to start machine unless you are sitting in operator's seat with the clutch switch depressed. DO NOT bypass or disable any of the starting system parts.

Set park brake before attempting to start engine.

This machine has a neutral start switch that is activated by the FNR/range lever (A).

Engage the park brake.

Check the neutral start system to ensure that the machine:

  • WILL start with the FNR/range lever in NEUTRAL.
  • WILL NOT start with FNR/range lever in any other position.

If starting system fails to operate correctly, have your authorized dealer repair the system immediately.
