Backhoe Auxiliary Hydraulic Function Switch-If Equipped

Push the backhoe auxiliary hydraulic function switch (A) to activate and deactivate backhoe auxiliary hydraulic attachments. The backhoe auxiliary hydraulic function switch has three positions:

  • Push upper half to activate the auxiliary hydraulic function.
  • Push to middle position to transfer control to the backhoe auxiliary hydraulic function foot switch.
  • Push lower half to deactivate the auxiliary hydraulic function.

The backhoe auxiliary hydraulic function indicator (B) will light when the backhoe auxiliary hydraulic function is activated.

See Backhoe Auxiliary Hydraulic Function Controls-If Equipped in this chapter for information on other backhoe auxiliary hydraulic function controls. See your backhoe auxiliary hydraulic attachment operator's manual for operational information.
