Inspect Air Cleaner Elements

IMPORTANT: Install a new primary element:

  • If element shows damage

  • If element will not clean

DO NOT clean secondary element.

Install new secondary element:

  • If primary element is damaged and needs replaced

  • If secondary element is visually dirty

NOTE: If gasket is broken or missing, install a new element.

Inspect elements for wear or damage. Clean primary element as necessary. (See Clean Air Cleaner Primary Element in this chapter for cleaning instructions.) Replace elements as necessary. (See Replace Air Cleaner Elements in Maintenance-Every 1000 Hours chapter.)
