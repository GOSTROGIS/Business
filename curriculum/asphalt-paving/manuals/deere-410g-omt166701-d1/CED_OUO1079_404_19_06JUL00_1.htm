Backhoe Auxiliary Hydraulic Function Controls-If Equipped

Use backhoe auxiliary hydraulic function switch (A), backhoe auxiliary hydraulic function foot switch (B), and backhoe auxiliary hydraulic function control pedal (C) to operate backhoe auxiliary hydraulic attachment.

See Operating Backhoe Auxiliary Hydraulic Functions-If Equipped in Operating the Machine chapter and your backhoe auxiliary hydraulic attachment operator's manual for operational information.

Push the lower half of the backhoe auxiliary hydraulic function switch to turn the backhoe auxiliary hydraulic function OFF when no attachment is installed, when changing attachments, or when installed attachments are not in use.
