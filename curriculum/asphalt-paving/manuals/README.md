Extract the ZIP and open `index.html`. All local manuals, images, styles, lessons and answer guidance work offline. The archive uses an internal `README-OFFLINE.md`; this repository README and the ZIP itself are excluded to avoid circular download links. External manufacturer/provider links remain online references.

The **pdfs/** files are full originals. The **extracts/** files contain short cover extracts and original identity/navigation notes; they are not complete manuals. The **deere-410g-omt166701-d1/** directory preserves the full retrieved original HTML collection. **manifest.json** identifies each model, serial/configuration scope, publication, source URL, date, size and hash. **deere-file-manifest.json** covers all 675 Deere files. **checksums.sha256** and **archive-info.json** record integrity evidence.

The standalone lesson uses real manual identities and fictional machine records to practise all nine Skills for Success. It includes individual digital actions, inclusive page-range arithmetic, an unresolved serial-range case, a written handover, check-back, shared verification, a changed record and a tested navigation aid. Four additional visual practices use faithful manual crops, precise trade vocabulary and worked examples: paver components, material delivery, roller components and dimension diagrams. APA-style figure notes and a full reference list credit the pictures. Instructor answers and criteria are separate.

The four PNG crops and [figure manifest](assets/figure-manifest.json) retain source hashes, original/printed page locations, crop coordinates and processing details. Regenerate them with `python curriculum/asphalt-paving/manuals/tools/extract_figures.py` (requires PyMuPDF), then rebuild this pack. Whole manufacturer PDFs are unchanged. These images introduce A1 and the vocabulary needed for I2, J1 and L1; they do not establish complete technical-unit coverage.

Section 4 of the uploaded outline lists six **course manuals**—Common Core, Raker, Compaction Roller, Screed, Paver and Milling Machine—and other resources. Those exact course publications were not retrieved. The OEM files are not relabelled as them. Read [the precise requirement and access gaps](access-status.md) for the provider route, historical CD titles and MS-4 handbook status. The complete [MS-4 textbook collection](../ms-4/README.md) is available separately as searchable HTML and 34 small PDFs; it is outside this OEM ZIP. CAT engine/fluids manuals do not replace a complete CAT paving-machine manual; Deere 410G is a backhoe-loader reference for supporting roadbuilding work.

Manufacturer copyright and notices remain intact. This is a dated reference collection, checked 29 October 2026, not a claim that every file is current for any actual machine. Confirm model, serial/configuration, current documentation and authorized training before practical application.

From the repository root, install `python -m pip install -r curriculum/asphalt-paving/tools/requirements.txt`, then run `python curriculum/asphalt-paving/manuals/tools/build_pack.py`. The build uses Markdown, Playwright and pypdf. It detects Chromium on PATH; set `IS4S_CHROMIUM_PATH` to choose another executable, or install the Playwright browser with `python -m playwright install chromium`. Original manufacturer files remain unchanged. Printed lesson links use stable repository URLs; offline navigation remains available through index.html.
