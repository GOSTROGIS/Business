# Design assets

The curriculum follows the ACCESS Numeracy Hub's existing design direction: warm cream `#F7F4F1`, white task sheets, ink `#1A1512`, slate `#4A4E54`, ACCESS red `#D2181F`, deep red `#C60016`, and gold `#FFBC00` for rules and highlight fills. Gold is not used for body text.

`is4s-badge.svg` is copied unchanged from [GOSTROGIS/access-trades-numeracy](https://github.com/GOSTROGIS/access-trades-numeracy/blob/7c0ceaab485e36aa45c596ac58e43bba63e4f824/brand/is4s-badge.svg). Its use follows that repository's [brand guidance](https://github.com/GOSTROGIS/access-trades-numeracy/blob/7c0ceaab485e36aa45c596ac58e43bba63e4f824/brand/BRAND.md). Keep its proportions, colours and wording intact.

Local font files provide Archivo headings, IBM Plex Sans reading text and IBM Plex Mono/tabular figures. The Fontsource package versions and integrity metadata are recorded in [fonts/manifest.json](fonts/manifest.json). The accompanying licence files are retained. The generated reading pages do not need a font-network request.

New layouts and activity wording are original curriculum-development material. The source PDFs remain unmodified in the source library.
