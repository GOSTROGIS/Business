# Practice data

All results, deliveries and dimensions are invented. In gradation.csv and running-means.csv, only the fields named **Historical_** reproduce selected 2006 specification limits; they are not current-project instructions. The selected rows are not a complete mix assessment.

| File | Contents and use |
|---|---|
| [gradation.csv](gradation.csv) | Six actual Table 501-E Medium Asphalt Mix intervals, with two fictional samples for SP-03–05 |
| [running-means.csv](running-means.csv) | Fictional results and curve values for SP-06–07; historical 4.75 mm interval/tolerance |
| [load-register-v1.csv](load-register-v1.csv) | Ten fictional loads for SP-09–13; preserve Ticket, Truck and Station as text |
| [area-records.csv](area-records.csv) | Two non-overlapping rectangles in versions 1 and 2 |
| [corrections-v2.csv](corrections-v2.csv) | Two replacement corrections, not added deliveries or duplicate area |

The spreadsheet layout in SP-12 assumes the supplied load CSV's five columns and header row. Save the working file in the spreadsheet application's format to retain formulas. CSV files themselves do not contain a completed workbook or proof of digital performance.
