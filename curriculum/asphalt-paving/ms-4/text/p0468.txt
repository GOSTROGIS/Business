4 Rolling Procedures

The goal of the compaction process is to achieve the required density in
as few coverages as necessary while preserving the smoothness and tex-
ture created by the paver. Rolling should start as soon as possible after the
HMA has been spread and can support the weight of the rollers without
lateral distortion.

9.4.1 Test Strip

A test strip should be built at the beginning of every project for each
mix or thickness to determine the proper roller pattern. The test strip
should be built at the same paving speed at which normal operation is
anticipated. The in-place density is checked after each coverage, using a
nondestructive gauge (nuclear or non-nuclear). A relationship between
number of coverages and density is determined while monitoring the
temperature of the mixture. This process helps determine the optimum
number of coverages for each roller in the rolling train and estimate the
dimensions of rolling zones for each roller. As shown in Figure 9.9, density
increases with each coverage, then peaks. The peak is relatively flat with
static steel-wheel rollers but very sharp with vibratory rollers. Care must
be taken to not go beyond the peak with vibratory rollers because the
density will decrease due to the mix being damaged.

Subsequently, during the compaction process, those involved must be
particularly observant and knowledgeable. A qualified quality-control
technician using a calibrated density gauge is invaluable in determining
the appropriate rolling pattern and adjusting the pattern as needed to
ensure that the target density level is achieved.

9.4.2 Determining Roller Requirements

The width of paving should be considered when selecting rollers. If a
wide pavement layer is constructed using narrow rollers, the rollers will
need to make many passes to completely cover the surface. This takes
time during which the mix will cool and differential density can result.
Generally, the width of the pavement is no more than three times the
width of the roller. Often the contractor selects two wide rollers operating
slightly offset from each other so that they effectively cover the width of
the mat each time they make a pass over the mat.
