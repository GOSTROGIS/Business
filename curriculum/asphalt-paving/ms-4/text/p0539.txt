Control Strip Density Specifications

Some agencies specify compaction requirements to meet a percentage
of a control strip density. Under these specifications, a test strip of HMA is
placed and compacted at the beginning of normal production paving. The
control strip is placed using specified or otherwise selected rolling proce-
dures and equipment. The intent is that the test strip be compacted to the
maximum achievable density, which then becomes the specified reference
density. Once the density of this control strip is established, the rest of
the paving is required to achieve a percentage of this density. These types
of specifications usually require the control strip to achieve a minimum
percentage of the laboratory density as well, to avoid mixtures that are
not compactable. This type of specification allows the relative difficulty
(or ease) of compacting a given mix to become a factor in establishing the
compaction requirements. New control strips are required for a different
mix design or pavement application.

Quality-control testing for this type of project includes in-place density
testing as described in 10.6.2, except that the compaction is calculated
differently.

As an example, consider a project that specifies compaction be at least
98 percent of control strip density, and the control strip density measured
for this particular application is 140.6 Ib/ft®? (2251 kg/m/%). If the quality-
control testing yields in-place density of 139.2 Ib/ft* (2228 kg/m*) at a
given location, then the compaction is calculated as follows:

Compaction = (4323 x 100| or (3328) x 100| = 99.0 percent

This compaction test result would comply with the specified minimum
value of 98 percent.

Method Density Specifications

Some agencies specify detailed means and methods to be followed for
compacting HMA. These methods include requirements such as size and
type of compaction equipment, and they usually include a specific num-
ber of passes with each roller. Such specifications are useful when placing
materials for which accurate density measurements are not easily made.
Examples of this are leveling courses and small quantity placements in
areas that carry little or no traffic.
