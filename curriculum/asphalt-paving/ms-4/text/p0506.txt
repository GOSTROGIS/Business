acceptance of the same parameter. Quality-control testing for compaction of
asphalt pavements, for example, quite often uses nuclear density test meth-
ods, whereas the acceptance testing for compaction may be performed using
bulk specific gravity test methods on cores cut from the finished pavement.
Test results from cores come too late to be used for adjusting the compaction
operation because the asphalt will have already cooled. Nuclear density tests
can be taken while the HMA is still hot and the compaction operation is ongo-
ing. Thus, nuclear density test results can be an important part of the overall
quality-control program for HMA compaction.

Since quality-control methods must emphasize timeliness and convenience,
the results can be less accurate and impart more variation in the data. If the
QC test method is different than the acceptance method, a minor shift in the
data should be anticipated. It would be unreasonable, for example, to stop
compaction operations when a reading of 95 percent compaction was read
on a nuclear density gauge, if the minimum required compaction was 95
percent using core densities. A higher target could be established to account
for the likely variation and the possible shift of compaction values from
the nuclear density method to the core density method. It is also a prudent
quality-control measure to correlate quality-control test methods and labo-
ratories to the acceptance methods performed by the acceptance laboratory.
This can be accomplished with several “split” samples from a test strip or at
the beginning of HMA production.

If a nuclear gauge is being used to control density and if an accurate corre-
lation to core densities has not been made, a “maximum density” method can
be used to overcome the variation from nuclear density test results and core
density test results. For this maximum density method, nuclear density read-
ings are taken in specifically marked locations between roller passes so that
the relative increases in compaction can be tracked throughout the compaction
operation. When the pavement reaches the highest achievable density (that is,
other rolling patterns yield lower density), then the pavement has achieved
a relative maximum density. Compaction should continue with the same pat-
tern until this relative maximum is achieved in other locations for that day’s
placement as well. Establishing rolling patterns is a trial-and-error process. It is
important to recognize that the number of vibratory passes in the breakdown
rolling will typically have a greater effect on the final compaction values than
the number of passes with a finish roller. Therefore, rolling patterns with vary-
ing initial breakdown passes should be included in the trial-and-error process.
A variety of rolling patterns may need to be tried before settling on the final
pattern. For more information on compaction of hot mix asphalt, refer to
Chapter 9, “Hot Mix Asphalt Compaction.”
