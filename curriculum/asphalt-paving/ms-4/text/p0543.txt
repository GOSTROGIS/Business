The total percent within limits (PWL,) is necessary if there are both
upper and lower limits. If there is only one limit, for example, a mini-
mum compaction value was specified, then only one percent within limits
would need to be determined. In the minimum compaction example, the
percent within the lower specification limit (PWL,) is used.
