A rolling pattern that provides the most uniform coverage of the lane
being paved should be used. Rollers vary in widths, and a single recom-
mended pattern that applies to all rollers is impractical. For this reason,
the best rolling pattern for each roller being used should be developed
and followed to obtain the most uniform density across the lane.

The rolling pattern includes not only the number of passes but also the
location of the first pass, the sequence of succeeding passes, and the over-
lapping between passes. Rolling speed should be consistent, with actual
speed depending on the roller type, as discussed earlier. In addition, sharp
turns and quick starts or stops are to be avoided because they can leave
tears or bumps in the mat.

Vibratory rollers allow for more options than static rollers. Dual-drum
vibratory rollers have power to both drums, so direction is not an issue.
It is possible to selectively vibrate the front drum, the rear drum, or both.
It is also possible to vibrate in one direction and run static in another. All
these variations not only offer limitless possibilities but also increase the
chance that a complicated rolling pattern will be forgotten or ignored. The
best rolling pattern is the one that results in a consistent density that meets
the target values. A simple pattern will be more consistently followed than
a complicated one.
