6.3.1 SW-1 Asphalt Pavement Thickness
Design Software

SW-1 is the Asphalt Institute’s Windows-based asphalt pavement
thickness design software that provides users a single computer-based
design solution for highways, airports, heavy wheel applications, and other
applications such as parking lots. It includes the Asphalt Institute pave-
ment design curves for highways, airports, heavy wheel loads, and other
applications, which have been digitized for use in SW-1. Also included
is the DAMA analysis tool for advanced structural analysis. Tying it all
together is a graphical user interface to ease handling of user inputs,
pavement design reports, and management of data files.

One of the benefits of SW-1 is a versatile and powerful user interface,
as shown in Figure 6.6. From this interface, users collect input data,
report output, and manage data files for asphalt pavement design for
all types of applications. SW-1 uses a tabular format to clarify the type
of input required and to aide the user in stepping through a pavement
design.

A design wizard is automatically invoked on the initial setup of a new
problem. The wizard steps the user through the process of inputting all the
required data—climate, traffic, subgrade, materials. The final step through
the wizard leads to a design solution and the report page.
