Pavement design solutions are viewed on a professional report page in
either summary or detailed versions. The Asphalt Institute logo is promi-
nently displayed on the design report to indicate that the design was
accomplished using the Asphalt Institute method.

SW-1 includes an extensive help file that is embedded in the software.
In addition, the companion SW-1 User’s Guide addresses common tech-
nical and operational questions. Both the help file and the User’s Guide
include numerous example problems that illustrate how the Asphalt Insti-
tute method can be applied to a specific problem.

In summary, SW-1 is a comprehensive design tool that provides users
with the power of all the Asphalt Institute design methods (design curves
and DAMA) in one convenient and easy-to-use software package. For more
information on SW-1, the user is referred to the Asphalt Institute Web site
at www.asphaltinstitute.org.
