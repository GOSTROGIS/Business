Identification practice

CAT-ID-01 · Reading · Communication

Follow the material
Open Figures 1–3 and 5. Name the paver’s two main sections. Identify the feeder chain, auger shaft and screed
plate. Explain to a partner how the feeder and augers have different roles. Have the listener point to each named
part.



CAT-ID-02 · Reading · Writing

Read every conveyor callout
In Figure 12, list names for callouts 1–7. Then write a two-sentence identification note for callout 5: assembly,
component, source publication and PDF page.



CAT-ID-03 · Numeracy · Problem solving

Count callouts without inventing quantities
Figure 12 has 7 callout numbers. Figure 13 has 6. How many distinct callout numbers are listed across the two
legends? If two identical classroom posters show Figure 12, how many numbered labels appear across those two
posters? Explain why neither calculation tells you how many replacement parts to order.

Identification practice

CAT-ID-04 · Reading · Problem solving

Check a roller-control match
Figure 14 identifies controls on the CB2.5 GC, CB2.7 GC and CC2.7 GC manual’s stated serial ranges. Locate 6, 12,
14 and 16. A fictional worksheet calls number 12 “engine start.” Correct it using the diagram.



CAT-ID-05 · Reading · Communication

Follow the loader letters
Use Figure 17. Find A, K, Y, S1 and S2. Describe the two connection points named for each pin. Ask a partner to
repeat the difference between S1 and S2.



CAT-ID-06 · Digital · Writing

Save a source you can find again
Search the CAT library for “tail pulley”. Open the hit from CAT-08 PDF page 25. Save a note containing publication,
revision, original PDF page, part filename and local viewer page. Close the note, reopen it and use it to return to the
same diagram.

Identification practice

CAT-ID-07 · Adaptability · Problem solving

Respond to a changed machine record
Fictional record A says: “950M, prefix EMB, automatic standard lift.” Record B corrects it to: “950M, prefix KSA,
standard lift; complete serial number not supplied.” Open CAT-17 PDF page 6. Mark which table row changes, what
information you must still obtain, and why the model name alone is insufficient.



CAT-ID-08 · Communication · Collaboration

Make a component check-back
In pairs, choose a cutting-chamber part in Figure 10. One person gives its callout, exact name, location and source.
The other finds it and restates the identification. Swap roles using a different part. Each person records one
correction or confirmation.



CAT-ID-09 · Creativity and innovation · Digital

Design a useful learning card
Create two layouts for a learning card containing one credited diagram, a part name, plain-language function and
model scope. Ask another reader to find the named part without help. Record what happened, choose a layout,
revise it and save the final file.

Identification practice

CAT-ID-10 · Reading · Writing · Collaboration

Complete a machine identification record
Use a supplied training machine record or one of the manuals in the library. Record model, serial applicability,
attachment, publication number/revision, assembly, page and callout. Mark unknown fields “to confirm”. A second
person checks the source match and signs or initials the classroom record.
