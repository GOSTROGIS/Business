Manual-reading lesson · Teaching and
answer guidance
Read the identity. Find the evidence. Explain the limit.




Prepare a complete document-reading session
Allow about 90–120 minutes for MAN-01–09, or divide that sequence into two sessions. Add about 45–60
minutes for VIS-01–04, with more time when needed for the full-size figures and actual device turns. These are
proposed ACCESS classroom practice times, not official technical-training allocations. Prepare the six original
OEM PDFs, the original Deere HTML manual, their covers/contents for print access, a PDF reader, a writable
practice folder and the fictional records. Do not place machines in this activity. Arrange actual device turns if
Digital is an intended observation. Confirm that all learners can reach a useful view and that practice IDs carry no
private data. Model page navigation using a different heading before assigning MAN-02. The Deere HTML
contents and local images/styles work without an internet connection.

The lesson teaches source selection, document navigation and a bounded handover. It does not award an
equipment endorsement or demonstrate maintenance performance. Cover matching is necessary evidence for
document selection; it does not establish every detail of actual-machine applicability. The manuals include original
technical instructions, but the lesson assesses finding and interpreting information, not carrying those procedures
out.

Use agreed access tools and record exact solving prompts separately. A learner can use text-to-speech and still
independently decide which serial statement applies. If the observer supplies the matching manual, that decision
has been supported. A missing device turn is Not observed for Digital, not an inferred failure. Invite another
attempt with changed fictional data after feedback.


Teach the visual vocabulary
Begin with the whole view, then a callout and its exact name. Model one sentence joining number + term +
function. Ask learners to explain the remaining terms in their own words. Pointing alone may show a location; it
does not yet demonstrate understanding of a function. Allow speech, signing, text or an agreed communication
aid, and preserve the learner's own decision.

Open the larger PNG or the source PDF when a callout is too small. Describe the part's position and supply the
accessible name table, without selecting the learner's answer. For the dimension page, keep both the diagram
and its table visible. Read letters and units aloud when useful. Do not infer a practical skill or assign an official
Skills for Success proficiency level from these classroom checks.
