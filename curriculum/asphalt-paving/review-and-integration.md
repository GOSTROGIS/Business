### A repeatable visual lesson pattern

1. **Name it.** Use the outline's term and one short plain-language definition.
2. **See it.** Place a real manual crop beside a simplified conceptual SVG where each has a clear teaching purpose. Keep component names readable at normal page size.
3. **Trace it.** Follow one material path, relationship or document-reading sequence. Use numbered arrows and a short text equivalent.
4. **Try it.** Give the learner a new label, comparison, quantity or decision to explain. A decorative image without a task adds little learning evidence.
5. **Check it.** Include the answer, a common misconception, the reason and the next practice in the instructor book.

This pattern supports the ACCESS tone through clear language, choice, respectful paired work and useful feedback. Community examples can be contributed voluntarily and locally attributed. Manufacturer diagrams should not receive invented Indigenous decorative motifs or claims of cultural endorsement.

## Figure attribution and fidelity

For a reproduced manual crop, use an adjacent note in this form, replacing every bracketed field with verified source details:

> **Figure [number]**<br>
> *[Short descriptive title]*<br>
> *Note.* From *[Exact manual title]* ([publication number/revision], p. [printed page], Figure [original number]), by [corporate author], [year], [official source URL]. Copyright [year] by [credited holder]. Cropped to show [content]; original labels retained. Full source: [local PDF viewer page].

Use **Adapted from** for a redrawn or annotated derivative. State the meaningful changes, such as simplified geometry, translated labels or added arrows. Do not write “reproduced with permission” unless permission is actually documented. An original ACCESS conceptual diagram should be labelled as original, with its technical source cited where relevant; it should not be represented as an MS-4 figure before that source is inspected.

For fixed publications, the reference list needs corporate author, year supported by the publication, italicized title, edition/revision or publication number where useful, and the source URL. Retrieval date belongs where the online content is designed to change; it is not a substitute for the manual's publication date. Preserve the full source's notices. APA attribution documents provenance; it does not itself establish a licence.

Keep a machine-readable asset record with: filename, original source path and SHA-256, one-based PDF page, printed page, original figure number, crop rectangle, pixel size, retained/added labels, transformation description, alt text, caption and reference entry. Before publishing, compare the crop with the complete page to ensure that conditions, scale information and relevant warnings have not been removed.
